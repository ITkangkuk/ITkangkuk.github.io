Troubleshooting

운영 및 개발 과정에서 겪은 문제를 분석하고 해결한 경험입니다.

Spring Scheduler 미동작 문제

원인: @EnableScheduling 누락

스케줄러가 실행되지 않는 문제를 분석했고, Spring 설정에서 @EnableScheduling 어노테이션이 누락된 것이 원인임을 확인했습니다.

Tomcat 다중 서버 캐시 불일치 문제

원인: 로컬 메모리 캐시 구조

여러 Tomcat 인스턴스가 하나의 DB를 사용하는 환경에서 캐시 데이터가 일치하지 않는 문제를 분석했습니다. Redis 기반 중앙 캐시 구조와 캐시 무효화 전략의 필요성을 검토했습니다.

Maven 멀티 모듈 구조 이해 및 적용
